# 🍴 Gourmet Galaxy

A modern Recipe Application built with React.js, Tailwind CSS, and TheMealDB API. Users can browse recipes, search meals, view detailed cooking instructions, watch recipe videos, and manage their favorite recipes.

## 📌 Features

- 🔍 Search recipes by name
- 🍽 Browse recipes from TheMealDB API
- 🏷 Filter recipes by category
- 📖 View detailed recipe instructions
- ▶ Watch recipe videos on YouTube
- ❤️ Add recipes to Favorites
- ❌ Remove recipes from Favorites
- 🔢 Live Favorites Counter in Navbar
- 🔔 Toast notifications for user feedback
- 📱 Responsive design for mobile and desktop

## 📦 Installation

### Clone Repository

```bash
git clone https://github.com/rkeerthikarajendran3366-create/recipe-app.git
```

### Move into Project Folder

```bash
cd recipe-app
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```

Application runs at:

```text
http://localhost:3000
```
